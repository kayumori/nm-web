# nm-web

Notion をデータの保存先として動く小さな Web アプリです。

## セットアップ

このリポジトリを Vercel にデプロイし、環境変数を 2 つ設定してください。

| 変数 | 内容 |
| --- | --- |
| `NOTION_TOKEN` | Notion インテグレーションのシークレット |
| `OWNER_PASSWORD` | 管理画面にログインするためのパスワード |

Notion 側には、所定の 2 つのデータベースを含むページを用意し、
上記インテグレーションを接続しておく必要があります。

手順の詳細は、配布時に案内しているマニュアルを参照してください。
